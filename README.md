# 北京中考数学真题知识点检索系统（2021–2025）

纯静态网页应用，无需任何依赖。数据库为 2021–2025 年北京市中考数学真题共 **140 道**（5年 × 28题），
全部来自网络公开的真题资料并经多来源交叉核对，题题含标准答案与详细解析。

## 使用方法

在项目目录启动任意静态服务器后访问 `index.html`，例如：

```bash
python -m http.server 8765
# 浏览器打开 http://localhost:8765/
```

（也可直接双击 `index.html` 打开，功能相同。）

## 分享给其他电脑

双击项目里的 **`一键分享到公网.bat`**，它会自动启动本地服务器和 Cloudflare 免费隧道，
并显示一个 `https://xxx.trycloudflare.com` 公网网址，把该网址发给别人即可访问。
注意：分享期间本机需保持开机；每次重启隧道网址会变化。
若需要固定网址的永久部署，可将本项目上传到 GitHub Pages / Netlify / Gitee Pages 等静态托管平台。

## 功能

1. **学期知识点与占比**：按七上→九下六个学期 + 综合题型列出全部知识点，
   显示每个知识点在近5年真题中的分值占比、题次与出现年份（占比 = 关联真题累计分值 ÷ 500）。
2. **模糊检索**：输入知识点的任意叫法（别名、俗称、英文如 sin），返回出现年份、真题原文、答案与解析；
   同时对题干全文匹配补充。
3. **出题思路分析**：基于真题库统计的命题特征（结构、固定题位、情境化、新定义压轴模式等），
   以及 28 个题位的近5年考点分布表、高频知识点 TOP12。
4. **模拟出题**：13 个模板对应真题稳定题位，按命题模式随机换参生成新题，附标准答案与完整解题过程。

## 目录结构

- `index.html` — 单页应用入口
- `css/style.css` — 样式
- `js/curriculum.js` — 知识点体系（规范名 + 模糊搜索别名）
- `js/questions-2021.js` … `questions-2025.js` — 各年真题库（id/题号/分值/题型/题干/答案/解析/知识点/是否含图）
- `js/app.js` — 统计、渲染、搜索逻辑
- `js/generator.js` — 模拟出题引擎

## 附：萌宠小屋（宠物养成小游戏）

`pet-game/` 是一个独立的宠物养成小游戏（Pawpal / 萌宠小屋），同样是纯静态页面、无任何依赖：
双击 `pet-game/index.html`，或启动静态服务器后访问 `http://localhost:8765/pet-game/` 即可游玩。

- 领养猫咪、小狗或兔兔，选颜色、起名字
- 喂食、洗澡、睡觉、摸摸头，照顾好它的饱食 / 心情 / 精力 / 清洁
- 玩“接零食”小游戏赚金币，在商店购买装扮；宠物会升级长大
- 进度自动保存在浏览器本地，支持中文 / English 切换

## 数据说明

- 含图题目已在题干中用文字描述图形要点，并以“含图”标签提示。
- 一道题可关联多个知识点，故各知识点占比之和大于 100%。
